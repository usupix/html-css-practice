# Машинка на CSS

Учебное задание: машинка нарисована с помощью CSS и одного HTML-элемента `<div>`.

- Ширина машинки — **200px**.
- При открытии страницы машинка выезжает слева и за **4 секунды** останавливается в **50px от правого края**.
- Дорога, солнце, облака и трава созданы средствами CSS.
- JavaScript, SVG и изображения не используются.

Откройте `index.html` в браузере. Чтобы повторить анимацию, обновите страницу.
